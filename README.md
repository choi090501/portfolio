# 집 가고싶다의 포트폴리오

게임과 음악을 좋아하는 학생의 관심사와 활동을 소개하는 웹사이트입니다.

## 나에 대해

저는 리그 오브 레전드와 이터널 리턴 같은 게임을 즐기고, 기타와 드럼을 배우는 뮤지션입니다. 학교 밴드부에서 활동하면서 여러 사람과 함께 음악을 만드는 경험을 하고 있습니다.

**관심사**: 게임, 음악, 악기 연주  
**잘하는 것**: 악기 배우기, 기타와 드럼 연주  
**목표**: 재미있게 살면서 새로운 도전을 계속하기

## 웹사이트를 만든 이유

친구나 선생님이 저를 더 잘 알 수 있도록 만들었습니다. 게임 플레이나 음악 활동처럼 제 관심사가 무엇인지, 어떤 경험을 했는지 한눈에 볼 수 있는 공간이 필요했습니다.

## 주요 화면과 기능

**홈**: 저를 한 줄로 소개하는 페이지입니다. 게임과 음악에 관심 있는 학생이라는 것을 바로 알 수 있게 구성했습니다.

**자기소개 페이지** (`#/about`): 
- 내 관심사 (롤, 이터널 리턴, 드럼)
- 잘하는 것 (악기 배우기, 기타, 드럼)
- 앞으로의 목표
- 학교 밴드부에서의 활동

**활동 페이지** (`#/portfolio`): 지금까지 경험한 활동들을 카드 형태로 보여줍니다.

**활동 상세 페이지** (`#/portfolio/website`): 각 활동에 대해 더 자세히 알 수 있습니다.
- 어떤 활동인지 (개요)
- 왜 했는지 (목표)
- 어떻게 진행했는지 (과정)
- 무엇을 배웠는지 (배운 점)

## 제작 과정과 배운 점

이 웹사이트는 GitHub Copilot의 도움을 받아 만들었습니다. 

**Copilot을 활용한 부분**:
- 페이지 구조와 React 컴포넌트 설계 도움
- 스타일링과 색상 선택 관련 조언
- 자기소개 내용을 정리하는 과정

**직접 선택하고 결정한 부분**:
- 게임과 음악이라는 관심사로 콘셉트 결정
- 진지하고 세련된 디자인 톤 선택
- 어두운 남색 계열 색상으로 변경 (기존 초록색에서 변경)
- 각 섹션의 텍스트와 설명 작성

**배운 점**:
- React에서 해시 기반 라우팅으로 페이지 이동 구현하는 방법
- CSS로 반응형 웹사이트 만드는 기본 개념
- 웹사이트를 통해 자신을 표현하는 방법

## 사용한 기술과 실행 방법

**사용한 기술**:
- React 19.3.1 (UI 라이브러리)
- Vite 8.3.4 (빌드 도구)
- JavaScript와 CSS (기능과 스타일)

**요구사항**:
- Node.js 24 LTS 이상

**실행 방법**:

1. 저장소를 클론합니다.
```sh
git clone https://github.com/choi090501/portfolio.git
cd portfolio
```

2. 의존성을 설치합니다.
```sh
npm install
```

3. 개발 서버를 실행합니다.
```sh
npm run dev
```

4. 터미널에 표시된 주소(보통 `http://localhost:5173`)를 브라우저에서 엽니다.

개발 서버는 파일을 수정하면 자동으로 브라우저에 반영합니다.

**배포 준비**:
```sh
npm run build
```

`dist` 폴더에 배포용 파일이 생성됩니다.

**코드 품질 확인**:
```sh
npm run lint
```

## 앞으로 개선하고 싶은 점

**현재 구현된 기능**:
- 홈, 자기소개, 활동 페이지 (텍스트 기반)
- 진지한 톤의 디자인
- 모바일과 데스크톱 반응형 대응

**앞으로 추가하고 싶은 기능**:
- 버스킹 공연의 사진이나 영상 추가
- 게임 플레이 영상이나 스크린샷 추가
- 더 많은 음악 활동이나 새로운 경험 추가
- 방문자가 메시지를 남길 수 있는 기능
- 다크 모드 추가

## 파일 구조

```
src/
  ├─ App.jsx       # 모든 페이지의 내용과 구조
  ├─ App.css       # 페이지 스타일과 색상
  └─ index.css     # 전체 공통 스타일
public/            # 사용할 이미지 등 정적 파일
.github/           # Copilot 작업 가이드
```
